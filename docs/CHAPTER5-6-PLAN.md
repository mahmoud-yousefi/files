## ۲) آیا آزمایش جدید لازم است؟

**نه، برای ادعای اصلی.** هفت نوآوری/هدفِ پروپوزال با exp1–exp10 پوشش داده شده‌اند:
هدف ۳ و ۴ (پیش‌پردازش/بهبود چارچوب) → exp7 (منفی) + exp8 (مثبت) + exp4/5 + exp9؛ هدف ۵ (تعمیم به TDSP) → exp1–3 + exp8؛ هدف ۶ و ۷ (کیفیت/زمان/همگرایی) → exp6 و exp10.

**دو کارِ اختیاری که فقط اگر داور سخت‌گیر شد لازم‌اند:**
- **۲ seed اضافه برای `size_v2` و `paper_v2`** (پروتکل exp5). الان بهترین عدد exp10 (`size_v2@3+rr = 0.996`) روی **یک** seed نشسته است، در حالی که armA/armB سه seed دارند. هزینه: ~۱ ساعت CPU برای هر ران (armA با ۲۰۰k اپیزود ۵٣۱۵ ثانیه بود). بدون این، جملهٔ فصل باید «یک seed» بماند.
- **بازاجرای exp6 روی بنچمارک ۱۶۸ نمونه‌ای exp10** اگر بخواهیم جدول «۱۳ بدتر / ۶ مساوی» را به جدول بزرگ‌تر ارتقا دهیم. در واقع exp10 خودش این کار را کرده (GRASP روی هر ۱۶۸ نمونه هست)؛ پس فقط باید در متن، **exp10 را مرجع اعلام کنیم و exp6 را تاریخی** — یک تصمیم روایی، نه یک اجرا.

## ۳) روایت فصل ۵ (هر بخش = یک ادعا + یک شاهد)

| بخش | ادعا | شاهد |
|---|---|---|
| ۵-۱ | TDSP تعمیم سادهٔ DSP نیست؛ قید «هر عضو باید همسایه در مجموعه داشته باشد» ساختار جواب را عوض می‌کند | تعریف + مثال P3 |
| ۵-۲ | ماسک مقاله **نمی‌تواند** TDSP را حل کند (قضیه، نه مشاهده) | قضیهٔ `independence_witness` + ۱۷۷/۱۷۷ |
| ۵-۲ | اگر بخواهیم TDSP را از DSP بسازیم، کران `|S| ≤ 2|D|` تضمین‌شده است ولی تنگ نیست | exp1 |
| ۵-۳ | فضای عمل بازطراحی‌شده: انتخاب `v` فقط `N(v)` را راضی می‌کند، پایان = همه همسایهٔ داخل مجموعه دارند؛ همان قرارداد agent دست‌نخورده می‌ماند | اگریدنس ۱۱۸ چک + ۵۹/۵۹ |
| ۵-۴ | **پاداش**: پاداش gain مقاله روی TDSP بازدهٔ ثابت `n` می‌دهد ⇒ بی‌سیگنال برای کمینه‌سازی؛ `r = −1` بازده را `−|S|` می‌کند | اثبات Σgain = n + exp4/5 |
| ۵-۵ | **شبکه**: باگ مقیاس‌پذیری `Σ h_u` باعث انفجار Q با `n` می‌شد (n=300 → ۸۵٬۱۸۳)؛ `mean` + `mean_readout` آن را ثابت می‌کند | T7 + exp4 در برابر exp5 (`size`: 4.34 → 1.04) |
| ۵-۶ | **گراف**: قواعد کاهش کلاسیک یا نامعتبرند (برگ) یا در این بنچمارک‌ها فعال نمی‌شوند؛ اما **اجبارِ F** (seed کردن برگ‌ها، نه حذفشان) معتبر است و فقط هزینه را کم می‌کند | exp7 + exp8 (۴۶٫۶→۱۶٫۲ تصمیم) |
| ۵-۷ | **الگوریتم یادگیری**: D3QN کیفیت را عوض نمی‌کند، بودجهٔ آموزش را کم می‌کند | exp9 |
| ۵-۸ | **تقویت صفر-آموزش**: `remove_redundant` + ماسک top-k؛ k=3 بهینه، k=1 ≡ greedy | exp10 (k-sweep) |
| ۵-۹ | ارزیابی جامع: هم‌سطح GRASP با ۴–۲۵× سرعت، برتری واقعی روی HEX، و اعتراف به باخت روی BA | exp10 |
| ۵-۱۰ | **seed**: اثر اجبار در هر ۳ seed تکرار شد (کیفیت دقیقاً برابر، سرعت ۳٫۷×)؛ D3QN در هر ۴ مقایسهٔ زوجی سریع‌تر | exp8 multiseed + exp9 |
| ۵-۱۱ | تهدیدهای اعتبار: reps=10 در ER/BA، ILP فقط n≤120، roll-out حریصانه (بدون نمونه‌گیری)، تک-seed بودن size_v2/paper_v2 | صادقانه |

**خط روایی پیشنهادی:** «یک ادعای روش‌شناختی، سه بهبود، دو نتیجهٔ منفی/خنثی.» یعنی:
1. ماسک مقاله را نمی‌شود قرض گرفت (قضیه) → ۲. پاداش را از «پاداشِ مقاله» به «هزینهٔ هر تصمیم» بردیم → ۳. باگ مقیاس شبکه را پیدا کردیم (این تنها جایی است که *کیفیت* واقعاً جهش کرد) → ۴. گراف: کاهش بی‌فایده، اجبار طلا → ۵. الگوریتم: D3QN ارزان‌تر، نه بهتر → ۶. تقویت خروجی: بزرگ‌ترین برد رایگان، و افشای یک بی‌عدالتی در مقایسهٔ قبلی خودمان.

این ساختار، فصل ۶ را هم تقریباً خودکار می‌کند: هر «بهبود» یک جملهٔ «چه چیزی یاد گرفتیم» دارد و دو موردِ منفی، اعتبار کار را بالا می‌برند.
